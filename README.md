# Tree-sitter Minecap

Minimal Tree-sitter grammar for `.minecap` syntax highlighting.

Supports:
- Section headers
- Basic expressions
- Magnitude `|x|`
- Derivative postfix `'`

## Zed usage (dev extension)

Use the dev extension in `editor/zed-extension`.

## Local build (optional)

```bash
npm install
npx tree-sitter generate
```
